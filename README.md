## About the CompTIA Security+ SY0-801 Exam

CompTIA Security+ is a vendor-neutral, entry-to-intermediate cybersecurity certification. It validates the baseline skills needed to assess security posture, secure hybrid environments, monitor and respond to incidents, and operate with an awareness of governance, risk, and compliance.

The SY0-801 exam is relevant for:

- Security administrators and analysts
- Network and systems administrators moving into security
- Help desk and IT support staff building a security career
- Students and career changers entering cybersecurity
- Government and contractor roles that require baseline security certification

## Exam Domains and Study Topics

> 📌 Domain names and weightings below follow the structure of the current Security+ blueprint. Verify them against the official SY0-801 exam objectives PDF from CompTIA before you rely on them.

### 1. General Security Concepts
- Security controls: technical, managerial, operational, physical
- CIA triad, non-repudiation, AAA (authentication, authorization, accounting)
- Zero trust, gap analysis, change management
- Cryptographic fundamentals: symmetric and asymmetric encryption, hashing, digital signatures, PKI, certificates

### 2. Threats, Vulnerabilities, and Mitigations
- Threat actors and motivations
- Social engineering: phishing, vishing, smishing, pretexting
- Malware types, application attacks, network attacks
- Vulnerability types and mitigation techniques
- Indicators of compromise

### 3. Security Architecture
- Cloud, on-premises, hybrid, and virtualized environments
- Network segmentation, firewalls, IDS/IPS, secure protocols
- Data protection: classification, encryption, masking, tokenization
- Resilience and recovery: backups, high availability, disaster recovery

### 4. Security Operations
- Secure baselines, hardening, asset management
- Vulnerability management and penetration testing
- Monitoring, SIEM, logging, alerting
- Identity and access management: SSO, MFA, least privilege
- Incident response process and digital forensics basics

### 5. Security Program Management and Oversight
- Governance, policies, standards, and procedures
- Risk management: identification, assessment, analysis, treatment
- Third-party and vendor risk
- Compliance, audits, and privacy
- Security awareness training

## Sample SY0-801 Practice Questions

These are original sample questions for study purposes. For the complete, regularly updated question set with detailed explanations, visit **CertsTree.com**.

### Question 1
A user receives an email appearing to come from the IT department, asking them to log in through a link to "verify" their account. Which type of attack is this?

- A. Whaling
- B. Phishing
- C. Pharming
- D. Tailgating

<details>
<summary>Show answer</summary>

**Answer: B. Phishing**

Phishing uses deceptive messages to trick users into revealing credentials. Whaling targets senior executives specifically, pharming redirects traffic via DNS manipulation, and tailgating is a physical access attack.
</details>

### Question 2
Which security principle ensures a user is given only the access necessary to perform their job duties?

- A. Separation of duties
- B. Defense in depth
- C. Least privilege
- D. Job rotation

<details>
<summary>Show answer</summary>

**Answer: C. Least privilege**

Least privilege limits access rights to the minimum required, reducing the impact of compromised accounts or insider threats.
</details>

### Question 3
An organization wants to confirm that a file has not been altered during transfer. Which cryptographic function is MOST appropriate?

- A. Symmetric encryption
- B. Hashing
- C. Obfuscation
- D. Key stretching

<details>
<summary>Show answer</summary>

**Answer: B. Hashing**

A hash produces a fixed-size digest. If even one bit of the file changes, the digest changes, which verifies integrity.
</details>

## Study Plan

A suggested 6-week plan for candidates with some IT background:

| Week | Focus |
| --- | --- |
| 1 | General Security Concepts and cryptography basics |
| 2 | Threats, vulnerabilities, and mitigations |
| 3 | Security architecture and network security |
| 4 | Security operations, IAM, and incident response |
| 5 | Governance, risk, and compliance, plus first full practice exam |
| 6 | Review weak areas, performance-based question practice, final mock exams |

**Tips:**
- Take a practice exam early to find your weak domains.
- Study the *why* behind each answer, not just the answer.
- Practice performance-based questions, since they take more time than multiple choice.
- Memorize common port numbers and protocols.

## Exam Day Tips

- Flag PBQs and return to them after the multiple-choice questions if time is tight.
- Read every question for qualifiers such as **MOST**, **BEST**, **FIRST**, and **LEAST**.
- Eliminate clearly wrong options before choosing.
- Do not leave any question unanswered.
- Arrive early, or complete the online proctoring system check in advance.
